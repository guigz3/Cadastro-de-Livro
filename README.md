# Cadastro de Livro

Sistema desktop para cadastro e gerenciamento de livros, desenvolvido em C# com WPF, 
como projeto de estudo para praticar OOP e .NET.

## Sobre o projeto

Aplicação CRUD simples que permite cadastrar, listar, editar e excluir livros, 
com persistência de dados via Entity Framework Core e SQL Server LocalDB.

## Funcionalidades

- Cadastro de livros (título, autor, gênero, ano de publicação, ISBN)
- Listagem de todos os livros cadastrados
- Edição de dados de um livro existente
- Exclusão de livros

## Tecnologias utilizadas

- C# / .NET
- WPF (Windows Presentation Foundation)
- Entity Framework Core
- SQL Server LocalDB
